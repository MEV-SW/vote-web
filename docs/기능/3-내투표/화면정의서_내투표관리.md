# 화면정의서_내투표관리

- 기능요청: [#3](https://github.com/MEV-SW/vote-web/issues/3)
- **디자인 경로**: 클로드 직행 (§2)
- 작성: 채윤성 / 승인: 미정
- **디자인 시스템**
  - Figma 라이브러리: 없음 (내부 도구, 기존 화면 스타일 재사용)
  - 코드 토큰·컴포넌트: `src/index.css`, `src/pages/admin/ManagePage.tsx`
  - 쓸 컴포넌트: 기존 관리 화면. 전역 대시보드를 만들지 않는다

API는 [vote-server API스펙_생성자소유권](https://github.com/MEV-SW/vote-server/blob/main/docs/기능/4-소유권/API스펙_생성자소유권.md). Blocked by server #4, web #2.

## 화면 목록
| # | 화면명 | 진입 경로 | 비고 |
|---|---|---|---|
| 1 | 내 투표 목록 | `/admin` | 서버가 필터한 목록 |
| 2 | 수정 | `/admin/polls/:pollId/edit` | 타인 403 |
| 3 | 운영 결과 | `/admin/polls/:pollId/results` | 타인 403 |

## 화면별 정의
### 1. 내 투표 목록
- **구성**:
  ```
  상단  내가 만든 투표·폼 안내
  본문  기존 관리 테이블 — 서버 응답 행만
  ```
- **표시 데이터**: `GET /admin/polls` (소유 행만)
- **액션**: 만들기 / 수정 / 결과 / 시작·종료 / 삭제. 동작은 기존과 같다
- **상태**: 로딩 / 빈 목록(내가 만든 것이 없음) / 오류. 빈 목록과 로딩은 구분
- **권한**: 로그인한 호스트. 목록에 타인 항목이 있으면 버그다

### 2. 수정
- **구성**: 기존 수정 화면
- **표시 데이터**: `GET /admin/polls/{id}`
- **액션**: 기존 저장·문항/후보 편집
- **상태**: 403이면 `/admin`으로 이동. 404/오류는 메시지
- **권한**: 해당 항목 소유자

### 3. 운영 결과
- **구성**: 기존 결과 화면
- **표시 데이터**: 소유자 결과 API
- **액션**: 종료/재개·CSV
- **상태**: 403이면 `/admin`으로 이동
- **권한**: 해당 항목 소유자
