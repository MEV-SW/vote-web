# 화면정의서_인터뷰폼

- 기능요청: [#1](https://github.com/MEV-SW/vote-web/issues/1)
- **디자인 경로**: 클로드 직행 (§2)
- 작성: 채윤성 / 승인: 미정
- **디자인 시스템**
  - Figma 라이브러리: 없음 (내부 도구, 기존 화면 스타일 재사용)
  - 코드 토큰·컴포넌트: `src/index.css`, `src/styles/form.css`
  - 쓸 컴포넌트: `btn` / `cp-input` / `cp-field` / `pill` / `CreatePollModal` / `QuestionEditor` / `FormResultsView` / `VoteVerifyGate` / `SsoVerifyGate` / `ConfirmDialog` — 새 부품을 만들지 않는다

API는 [vote-server API스펙_인터뷰폼](https://github.com/MEV-SW/vote-server/blob/de12da7c7246c80e44d9023236d10ecaf745c051/docs/%EA%B8%B0%EB%8A%A5/1-%EC%9D%B8%ED%84%B0%EB%B7%B0%ED%8F%BC/API%EC%8A%A4%ED%8E%99_%EC%9D%B8%ED%84%B0%EB%B7%B0%ED%8F%BC.md).

## 화면 목록
| # | 화면명 | 진입 경로 | 비고 |
|---|---|---|---|
| 1 | 참여 목록 | `/` | 투표/폼 배지 |
| 2 | 만들기 | `/admin` 모달 | `kind=form` |
| 3 | 폼 수정 | `/admin/polls/:pollId/edit` | 문항 편집 |
| 4 | 폼 응답 | `/polls/:pollId` | `kind=form`이면 VotePage 대신 |
| 5 | 제출 완료 | `/polls/:pollId/complete` | 기존 완료 화면 |
| 6 | 공개 결과 | `/polls/:pollId/results` | 객관식/척도만 |
| 7 | 운영 결과 | `/admin/polls/:pollId/results` | 개별 응답·CSV |

## 화면별 정의
### 1. 참여 목록
- **구성**:
  ```
  상단  제목 · 내 투표 링크
  본문  진행중 카드 목록 — 카드 반복
        └ 카드: 종류 배지(투표/폼) / 제목 / 마감
        종료 카드 목록 (동일)
  ```
- **표시 데이터**: `kind`, `title`, `status`, `closes_at`
- **액션**: 카드 클릭 → 응답 화면. 내 투표 → 로그인 또는 관리 목록
- **상태**: 로딩 / 빈 목록 / 오류. 빈 목록과 로딩은 구분
- **권한**: 누구나

### 2. 만들기
- **구성**:
  ```
  모달  종류(투표|폼) · 제목 · 대상(불특정|특정) · 확인 방식(PIN|SSO, 특정일 때)
        확인 후 만들기
  ```
- **표시 데이터**: 없음 (입력)
- **액션**: 만들기 → `POST /admin/polls` (`kind=form`) → 목록 갱신
- **상태**: 제출 중 / 오류
- **권한**: 앱 접근 토큰 있는 로그인 사용자

### 3. 폼 수정
- **구성**:
  ```
  상단  목록으로 · 제목 · 상태 칩 · 저장
  본문  소개 텍스트
        문항 편집기 — 문항 카드 반복
        └ 카드: 제목 / 타입 / 필수 / 보기 또는 척도
  ```
- **표시 데이터**: `PollOut.questions`
- **액션**: 저장 메타. 문항 추가/수정/삭제. 보기 추가/수정/삭제. 시작은 문항 1개 이상
- **상태**: 불러오는 중 / 저장됨 메시지 / 오류 / 403이면 `/admin`으로 이동
- **권한**: 해당 폼 소유자

### 4. 폼 응답
- **구성**:
  ```
  상단  제목 · 마감 카운트
  게이트  특정+PIN이면 PIN 게이트 / 특정+SSO이면 SSO 게이트 (불특정이면 없음)
  본문  문항 반복
        └ 단답·장문 입력 / 단일·다중 선택 / 1–5 척도
  하단  제출
  ```
- **표시 데이터**: 문항 `title`, `help_text`, `required`, `type`, `options`, `scale_min`/`scale_max`
- **액션**: 제출 → `POST /polls/{id}/responses` → 완료 화면
- **상태**: 로딩 / 오류 / 이미 제출 / 진행 중 아님. 게이트 미통과와 문항 화면은 구분
- **권한**: 불특정은 누구나. 특정은 PIN 또는 회사 계정 확인 후

### 5. 제출 완료
- **구성**:
  ```
  본문  완료 문구 · 목록으로
  ```
- **표시 데이터**: 없음
- **액션**: 목록으로
- **상태**: 해당 없음
- **권한**: 방금 제출한 세션

### 6. 공개 결과
- **구성**:
  ```
  상단  제목
  본문  문항별 집계 — 객관식 막대 / 척도 평균
        주관식 원문은 없음
  ```
- **표시 데이터**: `FormResultsOut.questions` (texts 비움)
- **액션**: 없음
- **상태**: 종료 전 403 안내 / 로딩 / 빈 응답
- **권한**: 누구나 (closed)

### 7. 운영 결과
- **구성**:
  ```
  상단  목록 · 종료/재개 · CSV
  본문  문항 집계
        개별 응답 목록 (이름/이메일 있을 수 있음)
  ```
- **표시 데이터**: 관리자 `form-results` (responses 포함)
- **액션**: CSV 다운로드. 상태 변경
- **상태**: 로딩 / 403이면 `/admin` / 오류
- **권한**: 해당 폼 소유자
